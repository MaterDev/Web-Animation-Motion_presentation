- **GIFs as UI, not memes**
  - One slime family, staged in real product contexts
- **Four contexts**
  - **Chat reaction:** an oversized sticker in a conversation
  - **Processing:** a GIF above a progress bar
  - **Away state:** a sleeping GIF with an "away" tag
  - **Presence:** the idle loop as an "online" mark
- **The companion device**
  - A scripted chat swaps the character's mood as the conversation plays: idle, eat, happy, sleep
  - Each mood is just a different GIF file
- **The format**
  - Works everywhere, no code; can't be paused or honour reduced motion without swapping the file
  - 256 colours, so gradients band
- **The pipeline**
  - Generated by a script: change a value, re-bake
