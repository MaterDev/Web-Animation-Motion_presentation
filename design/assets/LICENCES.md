# design/assets — third-party assets and their licences

Every file here is a public asset with a licence that permits use in a paid
conference talk. The sheet that uses each one prints the attribution line
below it. Check this file before adding anything; a mixed-licence source is
the failure mode the SL-12 direction warned about.
