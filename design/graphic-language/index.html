graphic language

Each stage of the presentation's technique spectrum gets its own identity, not just its own colour — a tint, a pixel symbol, a slide-code plate, and now a distinct idle motion per topic, so a slide reads as "this stage" before anyone reads a word of it, on the display it'll actually appear on. A talk about web animation should have its own supporting material demonstrate the thing it argues for.

Chip and key read differently on purpose. A material chip (see the system reference) is a flat colour-mix over a neutral base — right for a chassis surface. Here the tint sits almost directly on the LCD's own backlight, and the symbol is drawn in the same ink as everything else on screen, because this is the one place a section colour is genuinely signalling something — which stage is active — rather than decorating a panel.
Expanded visual language — a style preview per topic

Not one animation in a box but a small kit per topic, on one plate: the slide code, the name set in its own colour, a bigger animated multi-part mark, a divider, a technique- inspired pattern swatch (film ticks, cascading rules, an offset grid, scattered nodes, a raster dither, a facet lattice, circuit vias), and a second, independently-timed motion element with its own duration/easing readout — coherent as a set, distinct per topic.
