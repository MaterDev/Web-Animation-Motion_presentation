graphic language

Each stage of the presentation's technique spectrum gets its own identity, not just its own colour — a tint, a pixel symbol, a slide-code plate, a pattern — so a slide reads as "this stage" before anyone reads a word of it, on the display it'll actually appear on. Everything that differentiates a topic here is a graphic element. Motion is deliberately not one of them: every idle loop on this page runs the single --ease-liquid curve from the system reference, unchanged.

Chip and key read differently on purpose. A material chip (see the system reference) is a flat colour-mix over a neutral base — right for a chassis surface. Here the tint sits almost directly on the LCD's own backlight, and the symbol is drawn in the same ink as everything else on screen, because this is the one place a section colour is genuinely signalling something — which stage is active — rather than decorating a panel.
Expanded visual language — a style preview per topic

A full kit per topic on one plate — six graphic elements, not one logo: the slide code, the name in its own colour, the animated primary mark, a rule treatment (the divider itself is a motif, since a rule appears in every layout and gets seen constantly), three secondary glyphs deconstructing the primary mark for caption-size use, a four-step tint ramp so each topic reads as a small palette rather than one colour, and a pattern band. Every one of those differs per topic. The motion underneath them is identical across all seven, which is what lets the set read as one family rather than seven unrelated widgets.
