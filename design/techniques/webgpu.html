SL-14

webgpu

The GPU stops being a place you send pictures to and becomes a place things happen. Compute passes read and write storage buffers that never come back; a hundred thousand grains can be an interface, a grid of cells can be a toy, a flock can be an experiment, a world can be grown rather than drawn, and a model can run where the pen is. Six things WebGPU is for, each shown as a fragment of a product that could ship — because a technique on a coloured square teaches nothing about where you would reach for it.

Every number on this sheet is measured on this machine, now. The GPU writes its own clock at the start and end of each pass (timestamp-query), so cards print passes, not frames. Pipeline

what a frame costs on the GPU

A frame here is a list of passes. Each compute pass runs one program across a grid of workgroups; the render pass draws. Validation happens once, when the pipeline is created, so a pass costs what its work costs and nothing else — and because the GPU timestamps the start and end of every pass, the cost is a measurement rather than a guess. Switch passes off and watch the bars: the scene loses the pass's effect and the frame loses exactly its time.

Storage buffers · compute

particles as interface

The oldest WebGPU demo is a particle system, and it is usually a screensaver. It is more useful as an interface: when a hundred thousand grains live in a storage buffer and a compute pass moves every one of them each frame, text can be made of sand, a refresh can be a swarm, a switch can pour, a hero can part around the hand — and the CPU sends nothing per frame but the pointer. Neighbour state

things that depend on the cell next door

Some pictures cannot be computed one pixel at a time, because each cell's next value depends on its neighbours' current ones — sand falling, chemicals reacting, ink flowing. In WebGL that is a texture ping-pong at whatever resolution one quad can afford. In a compute pass it is the natural shape of the work: every cell reads its neighbourhood from one buffer and writes the next state to another, thousands of cells per workgroup, as many steps a frame as you like. The difference between a texture and a toy.

Atomics · sorting · indirect draw

populations big enough to be the content

Past a few thousand agents, the hard part is not moving them — it is letting them find each other. A scatter write (this bird counts itself into that cell) needs atomics; sorting by cell needs a writable buffer; both are things a fragment shader cannot do. With them, a quarter of a million agents can each consult their neighbours every frame, and a simulation becomes something a researcher, an architect or a game can put a question to.

Procedural generation

a world grown, not drawn

A downloaded map is a picture; a generated one is a process, and a process can be re-run with one number changed. A compute pass writes a million heights from noise, another routes water downhill across them, another carves where the water runs — and the result is a place with rivers that reach the sea and coasts that make sense, in a few dozen milliseconds, for every seed a player will ever press.

On-device inference

a model where the pen is

A neural network is matrix multiplies, and a compute pass is a good place for those. This model was trained in this repository — two layers, a hundred thousand weights, ninety-odd percent on the standard test set — and it runs on the GPU in front of you every time the pen lifts. No upload, no round trip, no API bill: a category of feature that did not exist client-side, and the one a room of designers has not considered.

What this sheet is holding itself to

  1. Name the pass, not the frame. Every GPU time printed here is one named pass between two timestamps.
  2. The zero is queried. Bytes per frame come from a counter on the device queue; the pointer and the uniforms are what crosses, and they are printed rather than rounded away.
  3. A readback is a stall with a number. Where a card asks the GPU a question — a fragment count, a digit — it prints what the asking cost.
  4. Raw WGSL, no library. The storage buffers, the workgroups, the atomics and the sort are the argument.
  5. Every product is invented. Atlas, Nectar, Umbra, Field Notes, Grains, the Coral Reef Alliance's card, Tinta, the paper and its authors, Kingsway, Tessera and Sum! do not exist. The physics, the rule after Ballerini et al. 2008, the model's accuracy and every measurement are real.
