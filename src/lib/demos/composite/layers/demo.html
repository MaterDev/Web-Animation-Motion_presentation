1. What the user sees: one page.
    What the browser runs: three surfaces.
  2. DOM · HTML + CSS · on top

    Navigation, headline, price, the buy button and its focus ring. Needs semantics, interaction, accessibility.

  3. Canvas · WebGL / WebGPU

    The product, its light, the particle field. Needs pixels. Nothing inside can be read, so nothing that must be read goes there.

  4. Video · at the back

    The ambient loop. Pre-rendered and fixed, which is fine while it never has to respond.

  5. Alternative · no GPU layer

    A still in place of the canvas. The DOM layer is unchanged, so switching the GPU layer off loses nothing a keyboard or screen reader needs.
