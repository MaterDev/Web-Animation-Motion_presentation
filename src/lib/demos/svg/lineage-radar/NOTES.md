# Lineage radar

## What it is
A broadcast weather radar over a projected world map. Each AI-history site is a precipitation cell whose radius is counted from the dataset (events on record plus arcs in and out, as of the readout year). A three-primitive SVG goo filter (`feGaussianBlur` → `feColorMatrix` → `feComposite`) welds overlapping cells into masses in raster space, with no path interpolation.

## Extraction changes
- It now runs inside the kit's shadow root. The ids are kept, and `document.getElementById` became `root.getElementById`.
- The `#wx-goo` filter moved into this demo's own `<svg><defs>`. `filter="url(#wx-goo)"` resolves inside the shadow root. I checked this by removing the attribute on a live frame: cells that were fused went back to separate overlapping circles.
- `WAM.clock` became `wam.clock` on a per-mount `createWAM({ root })` instance, disposed on unmount.
- The `ResizeObserver(fit)` is registered with the disposer.
- The IIFE and the missing-vendor fallback were removed, because the data is imported.
- The data became ES modules. `data/map.js` is a subset holding only `{ geo, layers: [layers[0]] }`, which is everything the radar reads, and its values are identical. `data/ai-history.js` is a full copy.
- `mount()` returns a dispose function.
- Added `data-testid`s: `lineage-radar` (paper root), plus `pipeline-stage-chrome`, `pipeline-stage-year` and `pipeline-stage-key`. The existing `pipeline-stage` and `pipeline-stage-bar` are kept.
- The sheet's section prose and the filter-graph bench (`pp-*`, `#pp-goo`) were not brought over.

## Carried over as-is
- `render(t)` carries a comment saying the field is "Eased so the field rests at both ends", but the code is `const u = t;`, which is linear. The sheet has the same mismatch.
- `massCount` treats cells as one mass at 0.92 × the sum of their radii. That approximates the threshold weld; it does not read the pixels.
- The radar's viewBox is derived from the projected site extents plus 90 units of padding, and it is not a constant.
- The sheet declares era tokens `--ai-*`, but this stage does not use them, so none were added to `:host`.
- The app-level `/vendor/fonts/*.woff2` 404 means the readouts render in a fallback mono in the viewer. The Doto year renders correctly.

## Assets
- `data/map.js`: generated by `scripts/vendor.js` from Natural Earth via world-atlas (public domain), projected with d3-geo. This is a subset (`geo` and `layers[0]`) of `design/vendor/map.js`, which is generated and gitignored, copied on 2026-09-17.
- `data/ai-history.js`: generated by `scripts/vendor.js` from `scripts/data/ai-history.js`. Per-entry sources are in that file.
- To refresh either file, run `bun run vendor` and re-copy.
