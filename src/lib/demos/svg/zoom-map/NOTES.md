# Survey-sheet zoom map

## What it is
A topographic survey sheet (cream stock, blue water, brown shoreline, red locator) that flies a camera from the whole world down to Dartmouth College, 1956, by animating a nested `<g transform>`. Labels are admitted by semantic zoom (rank, then collision), the coastline is held at one device pixel by inverse stroke-width, and the flight ends on the record card once the map runs out of geography.

## Extraction changes
- The markup, CSS and JS now run inside the kit's shadow root (`stage()`). The ids are kept because the shadow root makes them unique. `document.getElementById` became `root.getElementById`.
- The `#sv-stipple` pattern moved out of the sheet's document-level `svg-defs` holder and into this demo's own `<svg><defs>`. `url(#sv-stipple)` resolves inside the shadow root. I checked this by rendering at 2x with the stipple on and off: the dots are there.
- `WAM.clock` became `wam.clock` on a per-mount `createWAM({ root })` instance. The instance is disposed on unmount.
- The `ResizeObserver(fit)` is registered with the disposer and disconnected on unmount.
- The IIFE and its `if (!H || !M)` "run bun run vendor" fallback were removed, because the data is now imported rather than read from globals.
- The data became ES modules: `data/ai-history.js` and `data/map.js`, each with `export default`. They are full copies with the same values.
- `mount()` returns a dispose function that stops the clock (rAF, visibilitychange, IntersectionObserver, matchMedia listener) and the ResizeObserver.
- Added `data-testid`s: `zoom-map` (paper root), plus `frame-stage-plate`, `frame-stage-scalebar` and `frame-stage-record`. Everything the sheet already had is kept, including the `frame-label-<id>` labels.
- The sheet's section prose (`.fmt-case`) and the camera bench above the stage were not brought over.

## Carried over as-is
- Label sizes are measured with `offsetWidth` once at init, the same as the sheet. If the web fonts arrive after mount, the collision boxes keep the fallback-font widths.
- `.sv-record` sets `display: grid`, and that beats the UA `[hidden]` rule. The record card stays laid out and is shown or hidden by `opacity` alone, which is sheet behaviour.
- The hairline strokes read `window.devicePixelRatio` every frame, which is fine. Page scale comes from `paper.clientWidth / 960`, so the stage fills whatever width the host gives it.
- The sheet declares era tokens `--ai-t0…t3, --ai-now, --ai-ink`, but this stage does not use them, so none were added to `:host`.
- In the deck app, `/vendor/fonts/*.woff2` (Inter and JetBrains Mono) return 404 at app level. That is not this folder's problem, but it means the plate and labels render in a fallback mono in the viewer, while the sheet shows JetBrains Mono.
